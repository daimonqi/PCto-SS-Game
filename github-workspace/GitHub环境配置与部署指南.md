# 隔离环境：Github MCP 与环境部署指南

此工作区和指南用于 **隔离 Github 自动化部署、插件配置以及全环境联调时遇到的系统配置问题**，从今以后与具体的页面 UI 设计隔离开来，保证设计时不被锁门，部署时不被代码干扰。

---

## 🛑 为什么需要这个独立环境？

之前我们在 F 盘的 `aiUI` 文件夹直接写代码和设计 UI，但是遇到以下两大环境问题卡住了：

1. **Github MCP 插件的启动限制**：Github MCP 需要通过 `Docker` 后台服务作为运行的基石，而当前主机的 Docker 刚刚通过静默下载安装。
2. **Git 环境的缺失**：我们在本地缺少了系统原生的 git 环境，或者我未获得足够的 `github 个人令牌 (PAT)` 操作权限去直接自动在本地使用命令行提交。这导致最终只能通过在浏览器里手动拖拽静态文件来暴力更新。

将这部分抽离后，未来在这个工作区：**所有和部署有关的测试、工具报错、授权操作，全在这里面集中解决。**

---

## 🔧 当前进度与接下来的任务

我们目前已经做到：
✅ 打包并且下载了 600多MB 的 **Docker Desktop 安装包**并自动运行（等它安装完重启即可）。
✅ 使用备用手动覆盖方案，强行部署成功了第一版的绝佳 UI 页面。

接下来待完成的 **核心三步环境贯通（需要等你重启后完成）**：

### 1️⃣ 等待 Docker 完全苏醒
安装完成后并重启电脑，保证电脑右下角的系统托盘里有一个【蓝色大鲸鱼🐳 (Docker)】的图标是常驻运行的。它是 Github 自动化推拉代码的隐身跑道。

### 2️⃣ 在此处重新呼叫 Github 链接
当你能稳定打开这个新 Workspace 并且有网后，只需要发给我一句话：“**重新链接 Github**”。我会在这个独立环境中，重新走走通那个因为环境缺失而断掉的 MCP 握手机制。

### 3️⃣ 预备 Github 个人访问令牌（PAT）
如果你之前有过 `ghp_xxxxxxxx` 开头的通讯钥，如果找不到了或者没权限，需要你去浏览器点击：
[生成新的 PAT 令牌直达地址](https://github.com/settings/tokens?type=beta)
创建一个包含 **`repo`、`workflow`、`admin:repo_hook`** 权限的长期密匙供我们重新填入作为自动化部署通行证。
